# 🏎️ F1 Speed Visualization – Charles Leclerc

A Formula 1 data visualization project exploring Charles Leclerc's speed and telemetry during the 2024 Italian Grand Prix qualifying session at Monza.

## 📌 About the Project

Ever wondered how fast an F1 car actually goes around a racing circuit?

This project uses real Formula 1 telemetry data to analyze Charles Leclerc's performance around the Monza circuit. It explores speed variations, track positions, and braking patterns through Python visualizations.

## 🎯 Project Objectives

- Analyze car speed throughout a lap.
- Visualize the Monza circuit using positional data.
- Identify high-speed and braking sections.
- Understand how speed changes around different parts of a circuit.

## 🛠️ Tech Stack

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- OpenF1 API

## 📊 Visualizations

1. Speed vs. Elapsed Time
2. Circuit Map – Speed Distribution
3. Braking Zones Visualization
4. Speed Distribution Histogram

## 📡 Dataset

Telemetry data retrieved using the [OpenF1 API](https://openf1.org/).

The analysis includes 321 matched position and car telemetry samples for the selected lap.

## 🚀 How to Run

1. Clone this repository:

   `git clone https://github.com/GayatriPalodkar/F1-Speed-Visualization.git`

2. Install the required libraries:

   `pip install pandas numpy matplotlib requests

Open Charles_Leclerc_F1_Analysis.ipynb in Google Colab or Jupyter Notebook.

Run the notebook cells in sequence.
